# Excel Office.js Add-in Development Workspace

This repository contains a fully configured development workspace and boilerplate for building, testing, and bundling custom **Microsoft Excel Add-ins** using the modern **Office.js JavaScript API**.

It demonstrates a professional setup for automating spreadsheet workflows, interacting with Excel workbooks, and packaging the solution for production deployment.

## 🛠️ Tech Stack & Key Tools

*   **Core Languages:** TypeScript, JavaScript (ES6+)
*   **Frameworks & APIs:** Office.js (Excel JavaScript API)
*   **Module Bundling:** Webpack
*   **Compilation & Transpilation:** Babel, TypeScript Compiler (`tsconfig`)
*   **Code Quality:** ESLint
*   **Deployment:** XML Manifest configuration for Office sideloading

## 📁 Repository Structure

*   `/src`: Contain the core application source code and business logic for the Excel Add-in.
*   `/dist`: The compiled, production-ready distribution assets generated by Webpack.
*   `manifest.xml`: The mandatory definition file that registers the add-in within Microsoft Excel.
*   `webpack.config.js`: Custom bundler configuration mapping entry points and optimizing output.
*   `babel.config.json` & `tsconfig.json`: Modern JavaScript transpilations and strict type definitions.

## 🚀 Key Technical Competencies Demonstrated

*   **Office Add-ins Architecture:** Implementing custom task panes, ribbon commands, and managing the Office lifecycle.
*   **Excel Data Automation:** Reading, writing, and manipulating complex spreadsheet workbooks programmatically via asynchronous APIs.
*   **Modern Frontend Tooling:** Setting up an enterprise-grade build system with hot reloading, bundling, and strict static typing.
*   **Quality Assurance:** Integrating rigorous linting and structuring clean automated workflow validations using local spreadsheet samples.

## ⚙️ Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the local development server:**
   ```bash
   npm start
   ```

3. **Sideload the add-in:**
   Use the `manifest.xml` file to sideload the add-in into your desktop or web version of Microsoft Excel for testing.
